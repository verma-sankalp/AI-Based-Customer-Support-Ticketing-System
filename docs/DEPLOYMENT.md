# Deployment

## Frontend
- Deploy on Vercel or Netlify.

## Backend
- Deploy on Render, Railway, or AWS EC2.

## ML Service
- Deploy separately using Flask/FastAPI or containerized Python service.

## Database
- Use MongoDB Atlas for production.

## Recommended Environment Setup
- Set production API URLs.
- Use secure JWT secrets.
- Enable CORS for approved domains.
- Use indexed collections for performance.
